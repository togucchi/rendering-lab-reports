実験 03 は light、04 は heavy fragment。同じ形状を、描画順・depth prepass・固定カメラで比較します。描画方式は中庭のみ有効。順序はオブジェクト単位で、fragment 呼び出し数の実測ではありません。

実験 05 は同じ不透明オブジェクトを反復描画。個別 draw は N draws、Instanced draw は 1 draw。数は 1〜4096（初期値 256）。両側の実験・WGSL・個数・カメラ・倍率を揃え、B の Instancing だけ変更します。この欄のカメラは実験 03〜06、Instancing と個数は実験 05 のみ有効です。

Instancing は draw 呼び出しをまとめますが、頂点数・fragment 数の削減や高速化は保証しません。CPU/rAF は A/B 合計です。同数・同条件の画質一致を確かめ、時間の比較には A/A 個別と A/A instanced を別 run で計測してください。

Transform / color は 48 bytes × 4096 = 196608 bytes を初期化時に一度だけ転送し、A/B で共有。各側の使用範囲は N × 48 bytes、個数変更や毎フレームの instance 再転送・CPU transform 更新はありません。初期化コストはこの計測に含みません。

まず両側で実験・カメラ・倍率を揃え、B の描画方式だけ変更。Prepass は depth 10 + color 10 draws。CPU/rAF 合計と画質を確認し、常に速くなるとは仮定しません。WGSL 編集時の prepass 比較は同じ不透明 coverage / depth と、vertex position の @invariant 指定が前提です。discard・fragment depth の変更は別途検証してください。

06 · FlightHelmet · glTF metallic-roughness

B · PBR inputs

最初の選択時に同一 origin から GLB を取得します。

固定条件: exposure 1 · Reinhard tone mapping · direct light (−0.5, 0.8, 1) · radiance (3, 3, 3) · IBL / shadow なし。AO は直接光に適用しません。ORM は R=occlusion / G=roughness / B=metallic。テクスチャ無効時も material factor を保持します。トグルは入力の寄与だけを切り替え、標準 WGSL は全 texture を sample するため、texture fetch 数の削減は保証しません。

制限: KHR_materials_transmission は未対応です。レンズは不透明として描画され、glTF の完全な外観再現ではありません。Debug view は物理的な明るさの比較ではありません。

正面 3/4 / 背面の固定カメラ。Overdraw・Instancing・オブジェクト数はこの実験では無効。WGSL・PBR inputs・カメラ・倍率を A/B で揃えると A/A です。
