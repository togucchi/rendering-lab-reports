RENDERING LAB実験と検証の記録

Rendering Lab の実験ノート

描画の実装を小さな実験で確かめ、条件、変更内容、結果と限界を記録しています。各レポートは、冒頭で分かったことと検証範囲を示し、目的、条件、実装、結果の順に説明します。

実装が動いたこと、画像で観察したこと、時間を測った結果は分けて読みます。多くの計測は native の software GPU で行っており、ハードウェア GPU やブラウザーの性能を示すものではありません。

このページの構成

  1. 基準実装を確認する
  2. 条件を変えて比較する
  3. レポートの読み方

基準実装を確認する

  • 001 · プロシージャル中庭は、後続の比較に使う基準描画の記録です。実メッシュ、深度、Lambert lighting を使い、描画結果を取り出して検査できるかを確認しています。この段階では性能を比較していません。

条件を変えて比較する

  • 002 · 内部解像度の比較では、表示寸法を固定して内部解像度を 100/75/50% に変えています。輪郭の変化と、software GPU で反復測定した経過時間を比較します。
  • 003 · 描画順序と深度プリパスでは、視点と処理負荷をそろえ、描画順序と深度プリパスの違いを調べています。2 視点 × 2 種類の処理負荷 × 3 方式の画像と、native で直列実行した経過時間を確認できます。
  • 004 · 個別 draw と instancingでは、同じ静的配置を N 回の draw と 1 回の draw で描画しています。画像の一致、個数ごとの CPU コマンド記録時間、転送コストを検証します。
  • 005 · glTF / metallic-roughness PBRでは、FlightHelmet512 の 5 表示と入力の切り替えを検証しています。native release の実画像と 480 点の計測値があります。Khronos の参照画像との比較は未完了です。
  • 006 · 平行光源のシャドウマッピングでは、bias、接触部の影、PCF の調整で何が改善し、何が失われるかを比較しています。48 条件の画像、1440 点の native CPU 経過時間、固定カメラ経路の 24 フレームを記録しています。
  • 007 · SSAO の品質とコストでは、32 samples・full 解像度を基準に、一つずつ条件を変える OFAT で比較しています。AO-only と最終画像、840 点の native 経過時間、細い形状・halo・画面端での制限を確認できます。
  • 008 · CPU 視錐台カリングと距離 LODでは、同じ 81 フレームの経路を 4 方式で描画しています。誤った欠落や固定閾値での形状の切り替わりを確認し、CPU の選択処理とコマンド記録の時間を分けて測っています。

レポートの読み方

何のための実験かは「目的と問い」、固定したものと変更したものは「比較条件」、どこを作ったかは「行った実装」で確認できます。「結果」は計測値と画像の観察を分け、「考察と適用範囲」では結果を使える条件と未検証事項を示します。

対象コード、実行記録、再現コマンドは末尾の「再現と証拠」にまとめています。過去の測定に使ったソースと、後から行った文章の編集は区別しています。画像があることは、性能や実機での動作保証を意味しません。未計測の値は埋めずに残します。
