RENDERING LAB実験と検証の記録

Rendering Lab の実験ノート

小さな描画実験について、比較した条件、得られた結果、その根拠を記録しています。

レポート

  • 001 · プロシージャル中庭：実メッシュ、深度、Lambert lighting を使った基準描画です。
  • 002 · 内部解像度の比較：100/75/50% の実画像と、software GPU で反復測定した経過時間を比較し、結果の適用範囲を記録しています。
  • 003 · 描画順序と深度プリパス：2 視点 × 2 種類の処理負荷 × 3 方式の実画像を比較しています。native で直列実行した経過時間と、計測の限界も記載しています。
  • 004 · 個別 draw と instancing：同じ静的配置を N 回の draw と 1 回の draw で描画し、画像の一致、個数ごとの CPU コマンド記録時間、転送コストを検証しています。
  • 005 · glTF / metallic-roughness PBR：FlightHelmet512 の 5 表示と入力の切り替えを検証し、native release の実画像と 480 点の計測値を記録しています。Khronos の参照画像との比較は未完了です。
  • 006 · 平行光源のシャドウマッピング：48 条件の実画像、1440 点の native CPU 経過時間、固定カメラ経路の 24 フレームを記録しています。bias、接触部の影、PCF の調整で何が改善し、何が失われるかを比較しています。
  • 007 · SSAO の品質とコスト：32 samples・full 解像度を固定基準とし、一つずつ条件を変える OFAT で比較しています。AO-only と最終画像を別々に保存し、840 点の native 経過時間と、細い形状・halo・画面端での制限を記録しています。
  • 008 · CPU 視錐台カリングと距離 LOD：同じ 81 フレームの経路を 4 方式で比較しています。誤った欠落がないか、固定閾値で形状が急に切り替わる様子を確認し、CPU の選択処理とコマンド記録の時間を分けています。

読み方

実装、自動テスト、実描画、ブラウザー操作は、それぞれの確認範囲を分けて記録しています。画像があることは、性能や実機での動作保証を意味しません。未計測の値は埋めずに残します。

各レポートには、対象コードの commit、実行条件、確認済み事項、未検証事項、画像、機械可読な実行記録を記載しています。

条件と証拠を残す、小さな描画実験。
