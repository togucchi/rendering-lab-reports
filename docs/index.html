RENDERING LAB実験と検証の記録

Rendering Lab / 実験ノート

小さな描画実験を、条件と証拠を添えて残す場所。

レポート

  • 001 · プロシージャル中庭：実メッシュ、深度、Lambert lighting の基準描画。
  • 002 · 内部解像度比較：100/75/50%の実画像、software GPUでの反復wall-timeと限界。
  • 003 · 描画順序とdepth prepass：2視点×2workload×3方式の実画像、直列native wall-timeと限界。
  • 004 · 個別 draw と instancing：同一の静的配置をN draws／1 drawで描画し、画像一致・個数別CPU encode・転送コストを検証。
  • 005 · glTF / metallic-roughness PBR：FlightHelmet512の5表示・入力toggle・native release実画像と480点。Khronos reference比較は未完了。
  • 006 · Directional shadow mapping：48条件の実画像、1440点のnative CPU wall time、24frameの固定camera path。bias・contact・PCFのtrade-offを比較。
  • 007 · SSAO quality / cost：32/full固定基準のOFAT、独立したAO-only/final画像、840点のnative walltime、thin/halo/screen-edge制限。

読み方

実装・自動テスト・実描画・ブラウザー操作を分けて記録します。画像があることは、性能や実機での動作保証を意味しません。未計測の値は埋めずに残します。

各レポートには対象コードの commit、実行条件、確認済み事項、未検証事項、画像と機械可読な実行記録を添えます。

条件と証拠を残す、小さな描画実験。
