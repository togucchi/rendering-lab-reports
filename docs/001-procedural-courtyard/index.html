RENDERING LAB実験と検証の記録

001 · プロシージャル中庭

床・囲い・箱・台座・UV sphere を組み合わせ、頂点属性・カメラ・深度・法線と光の関係を確認する基準シーンです。

結論

共有パイプラインで実メッシュを描画し、オフスクリーンの GPU readback を確認しました。実行 adapter は CPU software rasterizer の Mesa llvmpipe です。ハードウェア GPU の性能や、ブラウザー UI の動作を検証した結果ではありません。

512 × 512 の GPU readback を PNG に変換した画像です。ブラウザーや native ウィンドウのスクリーンショットではありません。

実装

  • CPU 生成の 1,221 vertices / 1,938 triangles。外部モデル・テクスチャなし。
  • Depth32Float、Lambert lighting、固定カメラの perspective projection。
  • 80-byte uniform。先頭 16 bytes は既存の fullscreen 実験と互換。
  • 中庭・解析球・色のパイプラインを同じ depth pass で切り替える検証。

対象と実行条件

対象コード commit: bcb259e6e5a8ebc9d11f132987a9a1e502c46010

  • Rust 1.99.0 / wgpu 30.0.1 / wasm-bindgen 0.2.129。
  • adapter: llvmpipe (LLVM 19.1.7, 256 bits)、backend: GL、device type: CPU。
  • driver info: 4.5 (Core Profile) Mesa 25.0.7-2+deb13u1。
  • オフスクリーン 512 × 512、時刻 0 秒、Rgba8UnormSrgb。
  • 実行日時は元ログにタイムスタンプがないため未記録。

ソースは別の private repository で管理しています。アクセス権がある場合、対象 commit を checkout し、Rust と WASM toolchain を用意して実行します。この公開サイトには実行用のソースは含まれません。GPU test には動作する native graphics adapter が必要です。上記コマンドの PPM 出力は PNG と同じ画素を持つ元形式です。
